Sprout Doctor
промпты для генерации

Всё, что можно сгенерировать нейросетью, чтобы заменить нарисованный кодом пиксель-арт: персонажи, противники, ферма, растения, интерьеры, иконки и музыка. Промпты на английском — генераторы понимают его лучше. Игра уже работает без этих файлов: каждый готовый файл просто заменяет временную графику.

  1. Начните с пунктов «Важно»: Аой, Фуку, Огава, Хайкаби, дом, лавка и фоны сцен. Остальное — по желанию.
  2. Одна картинка — один предмет или одна поза. Персонажей и предметы — на ярко-зелёном фоне (#00FF00): его я вырежу автоматически.
  3. Сначала сгенерируйте «главную» картинку персонажа, затем остальные позы делайте с ней в качестве референса (загрузите её в генератор), чтобы лицо и одежда совпадали.
  4. Если в генераторе есть поле «негативный промпт» — вставьте туда текст из блока ниже.
  5. Сохраняйте файлы с именами из серых плашек и пришлите архивом в чат. Я уменьшу их до игрового размера, приведу к палитре игры и встрою.
